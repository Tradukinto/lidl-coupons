# 🛒 Lidl Пафос (Кипр) — Скидки, Купоны семьи, Двойная выгода и Радар акций

**Telegram Mini App + Бот-уведомитель** для круглосуточного отслеживания скидок, акций супермаркета Lidl в Пафосе (*Tombs of the Kings 104, CY0119*) и купонов всех членов семьи с автоматической активацией, расчетом честных цен за 1 кг/л и мгновенными алертами в Telegram.

🌐 **Веб-приложение (GitHub Pages):** [https://tradukinto.github.io/lidl-coupons/](https://tradukinto.github.io/lidl-coupons/)  
🤖 **Telegram-бот:** [@lidlcouponsbot](https://t.me/lidlcouponsbot)

---

## ⚡ Краткий обзор: всё, что умеет приложение

| Раздел / Функция | Что делает (кратко и по делу) |
|---|---|
| **🔥 Комбо (Двойная выгода)** | Находит товары, где магазинная скидка суммируется с персональным купоном члена семьи. Рассчитывает финальную цену за 1 кг (или 1 л) и показывает, у кого активирован купон. |
| **🎟 Купоны семьи** | Мониторит 4 аккаунта (*Вова, Света, Влада, Сева*). Автоматически активирует все новые купоны в каждом аккаунте. Подсвечивает общие купоны-совпадения и точный срок действия. |
| **⚡ Супер-день (Great Deals)** | Однодневные супер-скидки Lidl (действуют строго 1 день). Переключение по датам недели и отдельная вкладка «Пересечения» с купонами семьи. |
| **🛒 Акции магазина (Daily Savers)** | Полный еженедельный каталог филиала в Пафосе с ценами за единицу веса/объема и кликабельным копированием кода SKU в буфер обмена. |
| **🏷 Категории** | Удобная фильтрация всего каталога: овощи/фрукты, молочка/сыры, мясо/рыба, пекарня, напитки, бакалея, сладости, непродовольственные товары (*Parkside*). |
| **🔔 Радар акций (Deal Radar)** | Отслеживание нужных продуктов (*йогурт, лосось, сыр, кофе, авокадо, parkside*). Умный 3-язычный тезаурус (RU/EN/EL), автодополнение и быстрые кнопки. |
| **🤖 Telegram-бот (@lidlcouponsbot)** | Мгновенные push-уведомления семье при появлении скидки на отслеживаемый товар. Удобное системное меню команд (`/start`, `/radar`, `/list`, `/add`, `/del`, `/clear`, `/help`). |
| **⭐ Список покупок** | Добавление товаров в список в 1 клик звёздочкой ☆. Чекбоксы вычеркивания купленного в магазине и прогресс-бар покупок. Сохраняется локально в браузере. |
| **💶 Евро-купоны** | Верхний баннер денежного купона на весь чек на кассе (например, скидка 1€ от 15€) с датой окончания и именем владельца. |
| **📖 Встроенная справка `?`** | Кнопка `?` в шапке открывает наглядную инструкцию прямо в интерфейсе приложения. Все кнопки снабжены краткими всплывающими подсказками. |
| **↻ Живой статус обновления** | Разделение времени каталога («Каталог от: ...») и времени сетевой проверки («Проверено: ...»). |
| **🛡️ Защита данных (Safeguard)** | Если в GitHub Actions временно истечет токен аккаунта, парсер не затрет базу, а сохранит богатые накопленные купоны и комбо. |

## 🚀 Быстрый старт и подключение

### 1. Подключение Mini App к Telegram-боту (1 минута)
Чтобы открывать витрину прямо из Telegram во весь экран смартфона:
1. Откройте чат с [@BotFather](https://t.me/BotFather) и отправьте `/setmenubutton`.
2. Выберите вашего бота (например, `@lidlcouponsbot`).
3. Введите URL: `https://tradukinto.github.io/lidl-coupons/`.
4. Введите текст кнопки: `🛒 Скидки Lidl`.
5. **Готово!** Внизу чата появится синяя кнопка меню для запуска приложения.

### 2. Подписка на уведомления Радара
1. Нажмите `/start` в боте [@lidlcouponsbot](https://t.me/lidlcouponsbot).
2. Бот автоматически зарегистрирует ваш `chat_id`.
3. При каждом обновлении каталога бот проверяет ваши отслеживаемые товары и присылает сообщение со ссылками и ценами.

## 🤖 Команды Telegram-бота

В боте настроено системное меню Telegram (`[/] Меню` слева от поля ввода):
- `/start` — Запуск бота и ссылка на витрину
- `/radar` — Проверить скидки по вашему списку прямо сейчас
- `/list` — Показать текущие отслеживаемые товары
- `/add <товар>` — Добавить товар в радар (например: `/add yogurt`, `/add сыр`, `/add parkside`)
- `/del <товар>` — Удалить товар из списка отслеживания
- `/clear` — Полностью очистить список отслеживания
- `/help` — Подробная справка по возможностям

### 3. Спецификация Lidl Plus API

Взаимодействие с API Lidl Plus выполняется через HTTP-запросы с эмуляцией официального клиента iOS:

#### 3.1. Заголовки (Headers)
```http
App-Version: 16.54.2
Operating-System: iOS
App: com.lidl.eci.lidlplus
Country: CY
Accept-Language: en (или el)
Authorization: Bearer <access_token>
```

#### 3.2. Обновление токена доступа (OAuth2 Refresh Token)
- **URL:** `POST https://accounts.lidl.com/connect/token`
- **Headers:** `Content-Type: application/x-www-form-urlencoded`
- **Body:** `grant_type=refresh_token&refresh_token=<REFRESH_TOKEN>`
- **Response:** JSON с полями `access_token`, `expires_in`, `refresh_token`.

#### 3.3. Получение персональных купонов
- **URL:** `GET https://coupons.lidlplus.com/app/api/v2/promotionsList`
- **Headers:** Стандартные заголовки + `Authorization: Bearer <access_token>`.
- **Response:** JSON со структурой `sections[].promotions[]`.
- **Поля акции:** `id`, `title`, `description`, `discount`: `{ amount, type: "PERCENTAGE"|"AMOUNT" }`, `validity`: `{ start, end }`, `isActivated`, `image`: `{ url }`.

#### 3.4. Активация купона
- **URL:** `POST https://coupons.lidlplus.com/app/api/v1/promotions/{coupon_id}/activation`
- **Headers:** `Content-Length: 0`, `Authorization: Bearer <access_token>`.
- **Response:** `200 OK` (купон активирован в аккаунте).

#### 3.5. Получение акций магазина (Daily Savers)
- **URL:** `GET https://offers.lidlplus.com/app/api/v4/{country}/{store_id}/offers`
- **Headers:** `App-Version: 16.1.3`, `Operating-System: iOS`.
- **Response:** JSON с акциями магазина, сгруппированными по секциям.
- **Детализация артикула (SKU):** `GET https://offers.lidlplus.com/app/api/v4/{country}/offers/{offer_id}` возвращает `productCodes.mainProducts[].code`.

### 4. Алгоритмы матчинга и бизнес-логика

#### 4.1. Алгоритм «Двойная выгода» (Комбо-скидки)
1. Товар участвует в акции магазина со скидкой $D_{store}$ (например, $-25\%$).
2. На тот же товар или категорию у одного из членов семьи есть персональный купон со скидкой $D_{coupon}$ (например, $-15\%$).
3. **Расчет цены:**
   - Цена магазина со скидкой: $P_{store} = P_{base} \times (1 - D_{store})$.
   - Финальная цена комбо: $P_{final} = P_{store} \times (1 - D_{coupon})$.
   - Честная цена за единицу веса: $P_{unit\_final} = P_{unit\_store} \times (1 - D_{coupon})$.
4. Сопоставление названий: нормализация строк (lowercase, удаление спецсимволов), сравнение корней слов и проверка вхождений.

#### 4.2. Алгоритм Радара и Тезауруса (`radar.py`)
- Каталог Lidl на Кипре содержит названия на английском и новогреческом языках, а пользователь может вводить запрос на русском (например, «лосось»), английском («salmon») или греческом («σολομός»).
- **Снятие греческой диакритики:**
  `ά->α, έ->ε, ή->η, ί->ι, ό->ο, ύ->υ, ώ->ω` и замена `ё->е`.
- **Проверка совпадений:**
  Для коротких слов ($\le 4$ символов) используется проверка границ слов `(^|\b|_)...($|\b|_)`. Для длинных слов — подстрочный поиск с весовыми приоритетами.

### 6. Защитный механизм от деградации данных (Defensive CI Safeguard)

В `lidl_parser.py` встроен защитный барьер:
```python
if os.path.exists(output_path):
    with open(output_path, "r", encoding="utf-8") as f:
        old_data = json.load(f)
        old_coupons_count = len(old_data.get("family_coupons", []))
        if len(web_family_coupons) < 5 and old_coupons_count > 20:
            # Защита от сбоя токенов в GitHub Actions: сохраняем купоны и комбо!
            payload["family_coupons"] = old_data.get("family_coupons", [])
            payload["double_deals"] = old_data.get("double_deals", [])
```
Это гарантирует, что если в облаке временно истечет токен одного из аккаунтов, витрина не сбросится в 0 комбо, а продолжит показывать актуальные данные.

### 7. CI/CD и автоматический деплой

Файл `.github/workflows/update_coupons.yml`:
- **Триггеры:**
  - `schedule`: `0 4 * * *` (07:00 Кипр) и `0 12 * * *` (15:00 Кипр).
  - `workflow_dispatch`: ручной запуск из вкладки Actions.
  - `push`: при коммитах в ветку `main`.
- **Секрет репозитория:** `LIDL_CONFIG_JSON` в настройках репозитория GitHub содержит актуальный `config.json`.
- **Деплой:** Артефакт папки `./web` публикуется на GitHub Pages через официальный action `actions/deploy-pages@v4`.

### 8. Инструкция по сопровождению и расширению

1. **Добавление нового магазина/города:**  
   Измените `store_id` (например, на `CY0118`) в `config.json`. Идентификатор магазина можно узнать в приложении Lidl Plus при выборе любимого филиала.
2. **Добавление нового члена семьи:**  
   Выполните `python manual_auth.py`, авторизуйте аккаунт и добавьте новый ключ в словарь `family_accounts` в `config.json`.
3. **Расширение тезауруса Радара:**  
   Откройте `radar.py` и добавьте новый продукт в словарь `BILINGUAL_THESAURUS` со списком синонимов на русском, английском и греческом языках.
