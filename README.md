# 🛒 Lidl Пафос (Кипр) — Скидки, Купоны семьи, Двойная выгода и Радар акций

**Telegram Mini App + Бот-уведомитель** для круглосуточного отслеживания скидок, акций супермаркета Lidl в Пафосе (*Tombs of the Kings 104, CY0119*) и купонов всех членов семьи с автоматической активацией, расчетом честных цен за 1 кг/л и мгновенными алертами в Telegram.

🌐 **Веб-приложение (GitHub Pages):** [https://tradukinto.github.io/lidl-coupons/](https://tradukinto.github.io/lidl-coupons/)  
🤖 **Telegram-бот:** [@lidlcouponsbot](https://t.me/lidlcouponsbot)

---

## ⚡ Краткий обзор: всё, что умеет приложение

| Раздел / Функция | Что делает (кратко и по делу) |
|---|---|
| **🔥 Комбо (Двойная выгода)** | Находит товары, где магазинная скидка суммируется с персональным купоном члена семьи. Рассчитывает финальную цену за 1 кг (или 1 л) и показывает, у кого активирован купон. |
| **🎟 Купоны семьи** | Мониторит 4 аккаунта (*Вова, Света, Влада, Сева*). Автоматически активирует все новые купоны в каждом аккаунте. Подсвечивает общие купоны-совпадения и точный срок действия. |
| **⚡ Супер-день (Great Deals)** | Однодневные супер-скидки Lidl (действуют строго 1 день). Переключение по датам недели и отдельная вкладка «Пересечения» с купонами семьи. |
| **🛒 Акции магазина (Daily Savers)** | Полный еженедельный каталог филиала в Пафосе с ценами за единицу веса/объема и кликабельным копированием кода SKU в буфер обмена. |
| **🏷 Категории** | Удобная фильтрация всего каталога: овощи/фрукты, молочка/сыры, мясо/рыба, пекарня, напитки, бакалея, сладости, непродовольственные товары (*Parkside*). |
| **🔔 Радар акций (Deal Radar)** | Отслеживание нужных продуктов (*йогурт, лосось, сыр, кофе, авокадо, parkside*). Умный 3-язычный тезаурус (RU/EN/EL), автодополнение и быстрые кнопки. |
| **🤖 Telegram-бот (@lidlcouponsbot)** | Мгновенные push-уведомления семье при появлении скидок. Интерактивные кнопки прямо в сообщениях, запуск витрины, умный 3-язычный ввод без `/add`, фоновый демон и системное меню (`[/]`). |
| **⭐ Список покупок** | Добавление товаров в список в 1 клик звёздочкой ☆. Чекбоксы вычеркивания купленного в магазине и прогресс-бар покупок. Сохраняется локально в браузере. |
| **💶 Евро-купоны** | Верхний баннер денежного купона на весь чек на кассе (например, скидка 1€ от 15€) с датой окончания и именем владельца. |
| **📖 Встроенная справка `?`** | Кнопка `?` в шапке открывает наглядную инструкцию прямо в интерфейсе приложения. Все кнопки снабжены краткими всплывающими подсказками. |
| **↻ Живой статус обновления** | Разделение времени каталога («Каталог от: ...») и времени сетевой проверки («Проверено: ...»). |

## 🚀 Быстрый старт и подключение

### 1. Подключение Mini App к Telegram-боту (1 минута)
Чтобы открывать витрину прямо из Telegram во весь экран смартфона:
1. Откройте чат с [@BotFather](https://t.me/BotFather) и отправьте `/setmenubutton`.
2. Выберите вашего бота (например, `@lidlcouponsbot`).
3. Введите URL: `https://tradukinto.github.io/lidl-coupons/`.
4. Введите текст кнопки: `🛒 Скидки Lidl`.
5. **Готово!** Внизу чата появится синяя кнопка меню для запуска приложения.

### 2. Подписка на уведомления Радара
1. Нажмите `/start` в боте [@lidlcouponsbot](https://t.me/lidlcouponsbot).
2. Бот автоматически зарегистрирует ваш `chat_id`.
3. При каждом обновлении каталога бот проверяет ваши отслеживаемые товары и присылает сообщение со ссылками и ценами.

В боте [@lidlcouponsbot](https://t.me/lidlcouponsbot) реализована гибкая интерактивная система управления:

### 1. Интерактивные кнопки прямо в сообщениях (Inline Keyboards)
Под каждым приветствием, ответом на команду и уведомлением прикреплены мгновенные кнопки:
- `🛒 Открыть приложение Lidl (скидки и купоны)` — запускает полноэкранное Mini App с картинками, фасовками и расчетом цен за 1 кг/л прямо внутри Telegram.
- `🎯 Проверить Радар сейчас` — выполняет мгновенную проверку совпадений скидок по вашим товарам.
- `📋 Мой список товаров` — выводит список всех позиций, отслеживаемых в данный момент.
- `➕ Добавить товар` — открывает интерактивную подсказку и примеры для добавления новых продуктов.
- `ℹ️ Инструкция` — открывает полную справку по всем возможностям системы.

### 2. Умный прямой ввод названий без команд: для чего это нужно
> 💡 **Зачем отправлять название товара боту:**  
> Чтобы бот поставил этот продукт на круглосуточный мониторинг и **автоматически прислал вам и вашей семье сообщение в Telegram, как только в Lidl Пафос на него появится скидка или персональный купон**.
> 
> **Вам не нужно учить команды или писать `/add`:** просто напишите боту в чат любое привычное слово — `йогурт`, `сыр`, `кофе`, `авокадо`, `лосось`, `масло` или `parkside`. Бот автоматически распознает продукт по встроенному 3-язычному тезаурусу (на русском, греческом и английском языках) и сразу добавит его в Радар акций семьи.

### 3. Системное меню команд Telegram (`[/] Меню` слева внизу)
При нажатии на кнопку **`[/] Меню`** (слева от поля ввода) открывается всплывающий список команд:
- `/radar` — 🎯 Проверить совпадения радара сейчас
- `/list` — 📋 Мои отслеживаемые товары
- `/add <товар>` — ➕ Добавить товар (например: `/add yogurt`, `/add сыр`, `/add parkside`)
- `/del <товар>` — 🗑 Удалить товар из списка отслеживания
- `/clear` — 🧹 Очистить список радара
- `/help` — ℹ️ Инструкция и возможности
- `/start` — 🚀 Главное меню и запуск витрины

### 4. Режим реального времени (Long Polling Daemon) и скрипты запуска
Бот работает в режиме Long Polling с временем отклика **менее 0.3 секунды** и встроенной защитой от дублирования сообщений. Для удобного запуска в Windows предусмотрены скрипты в корне проекта:
- `start_bot.bat` — запуск с открытым окном консоли (удобно для просмотра логов).
- `start_bot_background.vbs` — тихий запуск в фоновом режиме без всплывающих окон.

### 3. Спецификация Lidl Plus API

Взаимодействие с API Lidl Plus выполняется через HTTP-запросы с эмуляцией официального клиента iOS:

#### 3.1. Заголовки (Headers)
```http
App-Version: 16.54.2
Operating-System: iOS
App: com.lidl.eci.lidlplus
Country: CY
Accept-Language: en (или el)
Authorization: Bearer <access_token>
```

#### 3.2. Обновление токена доступа (OAuth2 Refresh Token)
- **URL:** `POST https://accounts.lidl.com/connect/token`
- **Headers:** `Content-Type: application/x-www-form-urlencoded`
- **Body:** `grant_type=refresh_token&refresh_token=<REFRESH_TOKEN>`
- **Response:** JSON с полями `access_token`, `expires_in`, `refresh_token`.

#### 3.3. Получение персональных купонов
- **URL:** `GET https://coupons.lidlplus.com/app/api/v2/promotionsList`
- **Headers:** Стандартные заголовки + `Authorization: Bearer <access_token>`.
- **Response:** JSON со структурой `sections[].promotions[]`.
- **Поля акции:** `id`, `title`, `description`, `discount`: `{ amount, type: "PERCENTAGE"|"AMOUNT" }`, `validity`: `{ start, end }`, `isActivated`, `image`: `{ url }`.

#### 3.4. Активация купона
- **URL:** `POST https://coupons.lidlplus.com/app/api/v1/promotions/{coupon_id}/activation`
- **Headers:** `Content-Length: 0`, `Authorization: Bearer <access_token>`.
- **Response:** `200 OK` (купон активирован в аккаунте).

#### 3.5. Получение акций магазина (Daily Savers)
- **URL:** `GET https://offers.lidlplus.com/app/api/v4/{country}/{store_id}/offers`
- **Headers:** `App-Version: 16.1.3`, `Operating-System: iOS`.
- **Response:** JSON с акциями магазина, сгруппированными по секциям.
- **Детализация артикула (SKU):** `GET https://offers.lidlplus.com/app/api/v4/{country}/offers/{offer_id}` возвращает `productCodes.mainProducts[].code`.

### 4. Алгоритмы матчинга и бизнес-логика

#### 4.1. Алгоритм «Двойная выгода» (Комбо-скидки)
1. Товар участвует в акции магазина со скидкой $D_{store}$ (например, $-25\%$).
2. На тот же товар или категорию у одного из членов семьи есть персональный купон со скидкой $D_{coupon}$ (например, $-15\%$).
3. **Расчет цены:**
   - Цена магазина со скидкой: $P_{store} = P_{base} \times (1 - D_{store})$.
   - Финальная цена комбо: $P_{final} = P_{store} \times (1 - D_{coupon})$.
   - Честная цена за единицу веса: $P_{unit\_final} = P_{unit\_store} \times (1 - D_{coupon})$.
4. Сопоставление названий: нормализация строк (lowercase, удаление спецсимволов), сравнение корней слов и проверка вхождений.

#### 4.2. Алгоритм Радара и Тезауруса (`radar.py`)
- Каталог Lidl на Кипре содержит названия на английском и новогреческом языках, а пользователь может вводить запрос на русском (например, «лосось»), английском («salmon») или греческом («σολομός»).
- **Снятие греческой диакритики:**
  `ά->α, έ->ε, ή->η, ί->ι, ό->ο, ύ->υ, ώ->ω` и замена `ё->е`.
- **Проверка совпадений:**
  Для коротких слов ($\le 4$ символов) используется проверка границ слов `(^|\b|_)...($|\b|_)`. Для длинных слов — подстрочный поиск с весовыми приоритетами.

### 6. Спецификация UI/UX и адаптивной навигации (Desktop & Mobile)

#### 6.1. Двухуровневая система навигации
1. **Основная строка (Primary Tabs):** 7 глобальных разделов (`🔥 Комбо`, `🎟 Купоны`, `⚡ Super`, `🛒 Daily Savers`, `🏷 Категории`, `⭐ Список`, `🔔 Радар`).
2. **Вторая строка (Secondary Sub-Row):** контекстные фильтры, отображаемые строго по условию:
   - Вкладка `🎟 Купоны`: чипы членов семьи (*Все, Пересечения, Вова, Света, Влада, Сева*).
   - Вкладка `🏷 Категории`: чипы продуктовых категорий (*Овощи/Фрукты, Молочка, Мясо...*).
   - Вкладка `⚡ Super`: переключатель между *«Все»* и *«Пересечения»*.

#### 6.2. Кроссплатформенная горизонтальная прокрутка
- **Проблема в браузерах на ПК:** Мышь на компьютере имеет только вертикальное колесо прокрутки (`deltaY`), из-за чего горизонтальные контейнеры со скрытым скроллбаром становятся недоступными за пределами экрана (вкладка `🔔 Радар` оказывалась скрыта за краем окна).
- **Архитектурное решение в `index.html`, `style.css`, `app.js`:**
  1. **Навигационные стрелки `‹` и `›` (`.chips-arrow`):** размещены с обеих сторон строки вкладок (`#nav-arrow-left`, `#nav-arrow-right`). При клике плавно прокручивают ленту на `140px`. Автоматически скрываются, если достигнут край или прокрутка не требуется.
  2. **Трансляция колесика мыши (Wheel-to-Scroll):** обработчик события `wheel` перехватывает вертикальное вращение колесика мыши и транслирует `deltaY` в горизонтальное смещение `scrollLeft`.
  3. **Перетаскивание мышью (Mouse Drag-to-Scroll):** поддержка жеста «схватить и потянуть» (grab and drag) для десктопных пользователей, аналогично сенсорному экрану, с защитой от случайного клика по вкладке при движении.
  4. **Автоматическое центрирование (Auto-scroll Into View):** при переключении на любую вкладку вызывается `element.scrollIntoView({ behavior: 'smooth', inline: 'center', block: 'nearest' })`, гарантируя, что активный раздел всегда находится в поле зрения.
  5. **Адаптивный скроллбар:** тонкий аккуратный скроллбар (`scrollbar-width: thin`) отображается на экранах с поддержкой указателя мыши (`@media (hover: hover)`).

### 7. Архитектура и спецификация Telegram-бота (@lidlcouponsbot)

#### 7.1. Двойной режим работы (Dual-Mode Architecture)
1. **Режим реального времени (Long Polling Daemon):**
   - **Точка входа:** `python telegram_notifier.py --daemon` (или запуск через `start_bot.bat` / `start_bot_background.vbs`).
   - **Механизм:** Непрерывный цикл опроса Telegram Bot API `getUpdates` с параметром `timeout=20` (Long Polling).
   - **Характеристики:** Мгновенный отклик на действия пользователя (**< 0.3 секунды**), нулевая паразитная нагрузка на сеть и процессор (соединение удерживается серверами Telegram до появления нового события).
   - **Отказоустойчивость:** Автоматический перехват сетевых исключений (`RequestException`, таймауты) с авто-реконнектом через 2 секунды.
2. **Пакетная синхронизация в CI (Batch Sync):**
   - Вызывается парсером `lidl_parser.py` в ходе планового пайплайна GitHub Actions (`0 4 * * *` и `0 12 * * *`).
   - Синхронизирует список подписчиков, обновляет `last_update_id` и рассылает дайджест новых найденных скидок на основе кэша `notified_deals.json`.

#### 7.2. Интерактивная навигация и запуск WebApp
- **Inline Keyboards в сообщениях:** Каждый ответ бота (на `/start`, `/help`, `/radar`, `/list` и в уведомлениях) содержит инлайн-кнопки прямо в теле сообщения:
  - Верхняя кнопка `🛒 Открыть приложение Lidl (скидки и купоны)` типа `web_app` — открывает полноэкранный интерфейс витрины на любых платформах (iOS, Android, Desktop, Web).
  - Кнопки быстрых действий (`🎯 Проверить Радар`, `📋 Мой список`, `➕ Добавить товар`, `ℹ️ Инструкция`) с `callback_data`.
- **Обработка Callback Query:** При нажатии на инлайн-кнопки вызывается `answer_callback_query`, немедленно скрывая спиннер загрузки в клиенте и возвращая результат.
- **Системное меню `[/] Меню`:** Метод `setMyCommands` регистрирует 7 команд (`/radar`, `/list`, `/add`, `/del`, `/clear`, `/help`, `/start`), а `ensure_chat_menu_button` активирует стандартную кнопку меню `commands` для всех чатов.

#### 7.3. Умный 3-язычный парсер ввода (Zero-Command Input & Tracking Trigger)
- **Целевое назначение:** Дать пользователю возможность мгновенно поставить товар на круглосуточный мониторинг без знания синтаксиса ботов и без набора команды `/add`.
- **Жизненный цикл события:**
  1. Пользователь отправляет в чат обычное название продукта (например: `йогурт`, `сыр`, `кофе`, `авокадо`, `salmon`, `parkside`).
  2. Текст анализируется функцией `expand_keyword_query(text)`. Если товар найден в тезаурусе `BILINGUAL_THESAURUS` (`radar.py`), он автоматически добавляется в список отслеживания (`tracked_items.json`) со всеми синонимами на греческом, русском и английском языках.
  3. Бот мгновенно отвечает подтверждением: сообщает, что товар взят на мониторинг, и прикрепляет инлайн-кнопки для немедленной проверки каталога.
  4. При каждом последующем обновлении данных (дважды в сутки через GitHub Actions или при запуске парсера) система сопоставляет отслеживаемые товары со скидками магазина, Great Deals и купонами семьи. При совпадении бот отправляет в Telegram пуш-уведомление с карточкой товара, скидкой и ценой.

#### 7.4. Защита от дубликатов (Debounce & Deduplication)
- При серии быстрых нажатий `/start` (например, при медленном мобильном интернете) функция `process_updates_list` объединяет входящую пачку обновлений и подавляет повторные команды от одного и того же `chat_id`, отправляя ровно один актуальный ответ.

### 8. Защитный механизм от деградации данных (Defensive CI Safeguard)

В `lidl_parser.py` встроен защитный барьер:
```python
if os.path.exists(output_path):
    with open(output_path, "r", encoding="utf-8") as f:
        old_data = json.load(f)
        old_coupons_count = len(old_data.get("family_coupons", []))
        if len(web_family_coupons) < 5 and old_coupons_count > 20:
            # Защита от сбоя токенов в GitHub Actions: сохраняем купоны и комбо!
            payload["family_coupons"] = old_data.get("family_coupons", [])
            payload["double_deals"] = old_data.get("double_deals", [])
```
Это гарантирует, что если в облаке временно истечет токен одного из аккаунтов, витрина не сбросится в 0 комбо, а продолжит показывать актуальные данные.

### 9. CI/CD и автоматический деплой

- **Триггеры:**
  - `schedule`: `0 4 * * *` (07:00 Кипр) и `0 12 * * *` (15:00 Кипр).

### 10. Инструкция по сопровождению и расширению

1. **Добавление нового магазина/города:**  
   Измените `store_id` (например, на `CY0118`) в `config.json`. Идентификатор магазина можно узнать в приложении Lidl Plus при выборе любимого филиала.
2. **Добавление нового члена семьи:**  
   Выполните `python manual_auth.py`, авторизуйте аккаунт и добавьте новый ключ в словарь `family_accounts` в `config.json`.
3. **Расширение тезауруса Радара:**  
   Откройте `radar.py` и добавьте новый продукт в словарь `BILINGUAL_THESAURUS` со списком синонимов на русском, английском и греческом языках.
4. **Управление Telegram-ботом в Windows:**  
   Для круглосуточного отклика бота дважды кликните `start_bot_background.vbs` (или добавьте ярлык в папку автозагрузки `shell:startup`). Для отладки используйте `start_bot.bat`.
