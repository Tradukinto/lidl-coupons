# 🛒 Lidl Пафос (Кипр) — Скидки, Купоны семьи и Двойная выгода

**Telegram Mini App** для круглосуточного отслеживания скидок, акций магазина Lidl в Пафосе и купонов всех членов семьи с автоматической активацией и расчетом финальных цен за 1 кг/л.

🌐 **Веб-приложение (GitHub Pages):** [https://tradukinto.github.io/lidl-coupons/](https://tradukinto.github.io/lidl-coupons/)

---

## ✨ Возможности

1. **🔥 Двойная выгода (Комбо-скидки):**
   - Автоматически находит пересечения между акциями магазина (*Daily / Weekly Savers*) и персональными купонами семьи (*Вова, Света, Влада, Сева*).
   - Рассчитывает **финальную цену за 1 кг (или 1 л)** после применения обеих скидок одновременно.
   - Показывает, у кого из членов семьи активирован нужный купон.

2. **🎟 Купоны семьи:**
   - Мониторит 4 семейных аккаунта.
   - **Автоматически активирует** все новые неактивированные купоны в каждом аккаунте.
   - Подсвечивает совпадения купонов между членами семьи уникальными цветными плашками.

3. **🛒 Акции магазина (Пафос):**
   - Каталог специальных предложений магазина **Pafos / Touristika (Tombs of the Kings 104, CY0119)**.
   - Финальные цены за 1 кг/л, цены за упаковку и официальные коды артикулов (SKU).

4. **📱 Удобный мобильный интерфейс (Telegram Mini App):**
   - Мгновенный живой поиск по названию товара, категории или артикулу (SKU).
   - Быстрые фильтры по членам семьи (*Все, Вова, Света, Влада, Сева*).
   - Копирование артикула товара в один клик по коду.
   - Полная поддержка темной и светлой темы Telegram, тактильный отклик (Haptic Feedback).

5. **⚙️ Круглосуточная автоматизация (GitHub Actions):**
   - Запуск обновления по расписанию: каждый день в **06:00 UTC (09:00 Кипр)** и в **13:00 UTC (16:00 Кипр)**.
   - Кнопка ручного запуска (**Run workflow**) в любой момент из интерфейса GitHub Actions.

## 🤖 Как подключить Telegram Mini App к боту (1 минута)

Чтобы открывать приложение прямо из Telegram в виде красивого окна на весь экран смартфона:

1. Откройте диалог с официальным ботом [@BotFather](https://t.me/BotFather) в Telegram.
2. Отправьте команду:
   ```text
   /setmenubutton
   ```
3. Выберите вашего существующего семейного бота (или создайте нового через `/newbot`).
4. Введите ссылку на веб-приложение:
   ```text
   https://tradukinto.github.io/lidl-coupons/
   ```
5. Введите название кнопки внизу чата:
   ```text
   🛒 Скидки Lidl
   ```
6. **Готово!** Теперь у всех членов семьи при входе в чат с ботом внизу всегда доступна кнопка **«🛒 Скидки Lidl»**, открывающая витрину на смартфоне.

## 🔐 Безопасность и хранение токенов

- Файл `config.json` со скрытыми токенами авторизации находится в `.gitignore` и **никогда не публикуется в репозитории**.
- В GitHub Actions токены передаются через зашифрованное хранилище секретов:
  - **Название секрета:** `LIDL_CONFIG_JSON`
  - Виртуальная машина GitHub Actions считывает конфигурацию во время запуска, выполняет активацию купонов и публикует на GitHub Pages **исключительно публичные данные каталога** (`web/data.json`), без каких-либо паролей или токенов.

## 💻 Локальный запуск

```bash
# Клонирование репозитория
git clone https://github.com/Tradukinto/lidl-coupons.git
cd lidl-coupons

# Установка зависимостей
pip install -r requirements.txt

# Создание config.json на основе шаблона
cp config.example.json config.json
# (Заполните актуальные refresh_token в config.json)

# Запуск парсера
python lidl_parser.py
```
